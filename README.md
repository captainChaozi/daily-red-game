# Daily Red (REDLINE)

Daily Red is a free browser game I built: every day you pick six level-100 Pokemon and try to beat Red's fixed team.

## How it works
- One fixed opponent team per day, so the puzzle is about team building and type coverage.
- Build a six-Pokemon lineup, then battle Red.
- Compare your lineup ideas with friends.

Play it here: https://daily-red.app/
